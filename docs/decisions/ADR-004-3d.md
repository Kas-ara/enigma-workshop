# ADR-004 — 3D with Three.js
Status: proposed.
Decision: Three.js, lazy-loaded; procedural geometry in v1; glTF models only with a verified licence recorded in CREDITS.md.
Requirements: 2D fallback when WebGL is unavailable; reduced animation with `prefers-reduced-motion`; no information available only in 3D.
Rejected: Babylon.js (heavier); 2D canvas as the main renderer (does not meet the 3D need).
