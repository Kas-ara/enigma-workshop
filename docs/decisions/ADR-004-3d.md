# ADR-004 — 3D with Three.js
Status: proposed.
Decision: Three.js, lazy-loaded; procedural geometry in v1; glTF models only with a verified licence recorded in CREDITS.md.
Requirements: the same machine is selectable in 2D, which is also the fallback when WebGL is unavailable; both views consume the same rotor and lamp state; reduced animation with `prefers-reduced-motion`; no information available only in 3D.
Rejected: Babylon.js (heavier); 2D canvas as the main renderer (does not meet the 3D need).
