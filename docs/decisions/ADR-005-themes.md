# ADR-005 — Themes and country representation
Status: proposed, pending user approval.
Decision: dark base; colour tokens per theme. Proposed themes: Army/Air Force (field grey), Navy (navy blue), Switzerland, Italy, Spain, and the codebreakers: Poland (Biuro Szyfrów), France, United Kingdom (Bletchley Park).
Forbidden: swastika, SS runes, eagle with swastika, any Nazi iconography (illegal in several countries, takedown risk).
Historical insignia, if relevant, are described in text, not reproduced.
